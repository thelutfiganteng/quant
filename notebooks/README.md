# Notebooks

This directory is for **exploratory analysis only** — not production code.

Use Jupyter notebooks here to:
- Explore new data sources
- Prototype nowcasting models
- Visualize backtest results
- Debug data quality issues

**Rules:**
- Never import production code from notebooks
- Don't commit notebook outputs (clear outputs before committing)
- If a notebook becomes useful, refactor it into `src/` as a proper module
